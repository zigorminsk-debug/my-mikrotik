Подключение к роутеру

Порты по умолчанию: RouterOS API — 8728 (с TLS — 8729), REST API — 80 (с TLS — 443). Рекомендуется включить в RouterOS /ip service api/rest и входить под администратором. Данные подключения используются и для применения конфигурации.

Конструктор конфигурации

Сначала подключитесь к роутеру на вкладке «Информация» — конструктор строится по данным конкретного устройства: модель, версия RouterOS, установленные пакеты и сетевые интерфейсы.

Interface
Интернет → WAN

Один или два канала DHCP / статический IPv4. Меньшая distance — основной канал. Для PPPoE пока используется отдельный раздел. VLAN провайдера нужно создать заранее.

DHCP: резервирование при потере lease/link. Ping статического шлюза НЕ проверяет интернет за ним. Существующие DHCP-клиенты и маршруты могут конфликтовать: проверьте конфигурацию перед применением. Настройки DNS задаются отдельно. Снятие галочки не удаляет ранее применённые настройки.

IP → Firewall → NAT

Каждое правило открывает доступ к локальному сервису. Без ограничения источника — для всего интернета. Проверьте порядок NAT и разрешение dstnat в цепочке forward: firewall автоматически не меняется.

Hairpin требует фиксированный внешний IPv4 и подсеть LAN. Для динамического IP используйте внутренний DNS. Повторное применение заменяет только правила mti-forward-*. Снятие галочки не удаляет настройки с роутера.
